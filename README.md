## 🚀 Jak wdrożyć na GitHub Pages

### 1. Utwórz repozytorium na GitHub
```bash
# Zainicjuj repozytorium Git
git init

# Dodaj pliki
git add .

# Pierwszy commit
git commit -m "Initial commit - ZLOT DURANGO 2026"

# Dodaj remote (zamień YOUR_USERNAME na swoją nazwę)
git remote add origin https://github.com/YOUR_USERNAME/zlot-durango-2026.git

# Wypchnij na GitHub
git branch -M main
git push -u origin main
```

### 2. Włącz GitHub Pages
1. Wejdź w **Settings** repozytorium
2. Przejdź do **Pages** (w lewym menu)
3. W sekcji **Build and deployment**:
   - Source: wybierz **GitHub Actions**
4. Strona automatycznie się wdroży!
